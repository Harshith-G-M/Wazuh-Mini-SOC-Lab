# L1 SOC triage checklist

- [ ] Confirm alert timestamp and timezone.
- [ ] Identify hostname, logged-on user and asset criticality.
- [ ] Review source IP, destination, logon type and process details when available.
- [ ] Check surrounding events before and after the alert.
- [ ] Compare activity with known baseline and approved changes.
- [ ] Look for corroborating telemetry; avoid conclusions from one event alone.
- [ ] Record evidence and queries/screens reviewed.
- [ ] Assign a reasoned severity and confidence.
- [ ] Close as benign with rationale, continue monitoring, or escalate per procedure.
- [ ] Do not isolate devices, disable accounts or delete files without authorization.
